# Perez Services Website

A polished static website for Perez Services, a cleaning and landscaping company in Lawrence, MA.

## Files
- `index.html` — website structure and content
- `styles.css` — full responsive design
- `script.js` — mobile menu behavior

## How to use
1. Open `index.html` in a browser to preview.
2. Replace the placeholder phone number, email, and form email.
3. Replace sample stock image links with real business photos when available.
4. Upload the folder to Netlify, Vercel, GitHub Pages, or another static hosting service.
